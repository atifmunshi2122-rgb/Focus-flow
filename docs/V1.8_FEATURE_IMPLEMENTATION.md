# FocusFlow & Finance v1.8.0 — Feature Implementation Architecture Specification

## Executive Summary
FocusFlow & Finance **v1.8.0** introduces **15 unique zero-AI features** specifically engineered for computer science students, engineering executives, and disciplined finance planners. Every feature is built upon deterministic mathematical algorithms, native browser APIs (such as Web Audio API and HTML5 Canvas), and secure multi-tenant persistence.

## Detailed Architectural Breakdown

### Feature 1: Time-vs-Money True Cost Converter
- **Mathematical Principle:** Converts expense amounts ($E$) to equivalent work hours ($H = E / R_{hourly}$) and standard 8-hour workdays ($D = H / 8$).
- **Display Formatting:**
  - $H < 1$: Formatted in minutes (e.g., `15 mins of work`).
  - $1 \le H < 8$: Formatted in hours and remaining minutes (e.g., `3h 15m of labor`).
  - $H \ge 8$: Formatted in workdays (e.g., `2.5 working days (20 hrs)`).
- **Settings Integration:** Configurable in `SettingsView.tsx` under Category F (Financial Standards) with an active toggle and hourly earning rate input in the user's primary currency.
- **UI Integration:** Rendered as inline badges (`TimeVsMoneyBadge`) in mobile card view, desktop table rows, and transaction details modals in `TransactionsLedger.tsx`.

### Feature 2: CS Student Built-in COA/Math Micro-Lab
- **Number Base Converter:**
  - Converts numbers between Binary, Decimal, and Hexadecimal.
  - Generates educational step-by-step arithmetic explanations (positional power expansion and successive division methods).
- **1's and 2's Complements:**
  - Supports 8-bit, 16-bit, and 32-bit registers.
  - Automatically calculates bitwise inversion and two's complement for positive and negative numbers.
- **IEEE-754 Floating-Point Explorer:**
  - Uses native JavaScript `ArrayBuffer` and `DataView` to inspect binary bit fields.
  - Decomposes floats into Sign bit (1-bit), Biased Exponent (8-bit single / 11-bit double), and Mantissa/Significand (23-bit single / 52-bit double).
  - Identifies special cases: Zero, Subnormal, Normal, Infinity, NaN.
- **Big-O Complexity Matrix:**
  - Visual points comparison table for $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$, and $O(2^n)$ at scale increments ($n=1, 5, 10, 20, 50, 100$).

### Feature 3: RPG-Style Interactive Skill Tree
- **Graph Traversal & Cycle Detection:**
  - Tarjan's 3-color DFS cycle detection algorithm (`hasCycle`) prevents circular prerequisite locks ($A \to B \to A$).
- **State Progression:**
  - Evaluates prerequisites automatically: `locked` $\to$ `available` $\to$ `in_progress` $\to$ `completed`.
- **Views:**
  - **SVG Directed Canvas:** Interactive connected graph with bezier curves and status-coded node markers.
  - **Roadmap Tier List:** Compact list view sorted by curriculum tiers.
- **Pre-loaded Tracks:** Includes CS Foundations, DSA Mastery, and Financial Independence presets with zero external dependencies.

### Feature 4: Built-in Rough-Work Whiteboard Canvas
- **Offscreen Buffer Invariant:** Employs an internal offscreen buffer canvas (`bufferCanvasRef`) so window resizes or device rotations never wipe existing drawings.
- **Drawing Tools:** Pen, Semi-transparent Highlighter, Eraser, Line, Rectangle, Circle.
- **Stack History:** Dedicated 20-depth undo/redo history stacks.
- **Export & Sync:** Allows local PNG snapshot downloads and optional attachment to study topic notes.

### Feature 5: Web Audio API Binaural Beats
- **Acoustic Synthesis:**
  - Employs native browser `AudioContext` with dual `OscillatorNode` instances routed through a stereo `ChannelMergerNode` (Left channel = Base carrier frequency; Right channel = Carrier + Beat frequency).
  - Smooth volume transitions using `linearRampToValueAtTime` to prevent audible clipping or pops.
- **Presets:**
  - **Alpha (10 Hz):** Flow state, relaxed alertness, reading.
  - **Beta (18 Hz):** Problem solving, active coding, high analytical focus.
  - **Gamma (40 Hz):** Peak cognition, memory consolidation, intense study.
  - **Theta (6 Hz):** Deep meditation, creative ideation, post-session rest.
- **Safety & UX:** Prompts users with stereo headphones advisory for optimal binaural entrainment.

### Feature 6: Today's Focus Receipt
- **Visual Design:** Thermal supermarket receipt aesthetic with monospace typography, barcode simulation, and tear-off edge stylings.
- **Metrics Computed:**
  - Total Study Minutes, Pomodoro Count, Tasks Completed, Active Streak, Productivity Score.
  - Financial summary with optional privacy masking (`hideFinancials` toggle).
- **Export Pipeline:** HTML5 Canvas rasterization with high-DPI rendering for PNG download and native Web Share API fallback.

### Feature 7: What-If Financial Sandbox
- **Non-Destructive Simulation:** Independent temporary state isolating sandbox alterations from actual transactions.
- **Projections:**
  - Monthly income slider ($-₹20k$ to $+₹50k$).
  - Category spending adjustments (Housing, Food, Subscriptions, Discretionary).
  - 1-Year and 5-Year compound savings projections based on customizable annual yield rates (e.g., 8% equity compounding).

### Feature 8: Exam Hall Sectional Simulator
- **Timed Sectional Engine:**
  - Section-based pacing clock with dynamic thresholds (Ahead, On Track, Behind, Critical).
  - Question flag and attempt status trackers.
- **Crash Recovery:** Automatic state checkpointing to `localStorage` every second to resume seamlessly on accidental page refreshes.
- **Performance Report:** Post-exam analytics displaying allocated vs actual time spent per section.

### Feature 9: Decision Journal
- **Structured Framework:** Records decision title, contextual rationale, expected outcome, confidence score (1-10), and review intervals (30-day / 90-day).
- **Retrospective Loop:** Scheduled review alerts prompting the user to evaluate actual outcomes against initial hypotheses with success ratings and lessons learned.

### Feature 10: Doomscroll Self-Tax Jar
- **Accountability Ledger:** Allows students to log distraction intervals (Instagram, YouTube Shorts, X, Gaming) with an hourly self-tax rate (e.g., ₹300/hr).
- **Discipline Balance:** Aggregates penalty balances in a simulated discipline jar.
- **Transfer to Goal:** Option to convert penalty balance into an actual deposit towards an active Savings Goal (e.g., "Emergency Fund").

### Feature 11: Life-in-Weeks Grid
- **Memento Mori Perspective:** 90-year horizon represented as a $52 \times 90 = 4,680$ week dot matrix.
- **Visual States:** Lived weeks, current week pulse indicator, and remaining future weeks.
- **Milestones:** Custom milestones mapped to specific chronological ages (e.g., "College Graduation", "First Software Job", "Financial Freedom").

### Feature 12: 60-Second Code-Typing Warmup
- **Motor Activation:** Pre-pomodoro 60-second typing warmup using real programming constructs in C++, JavaScript, and Python.
- **Zero Eval:** Deterministic character comparison avoiding `eval()` or dynamic code execution.
- **Real-time Feedback:** Live character accuracy highlighting, WPM calculation, and 1-click skip capability.

### Feature 13: Inflation-Adjusted Goal Calculator
- **Financial Formulas:**
  - Nominal Future Value: $FV = PV \times (1 + r)^n$
  - Purchasing Power Loss Factor: $\text{Factor} = (1 + r)^{-n}$
  - Compounding Monthly SIP: $PMT = \frac{FV \times i}{(1 + i)^m - 1}$ where $i = R/12$, $m = 12n$.
- **Sensitivity Matrix:** Multi-scenario matrix comparing required savings across varying inflation rates ($\pm 2\%, \pm 4\%$).

### Feature 14: Time Capsule Letter to Future Self
- **Cryptographic Seal Paradigm:** Letters are locked with an immutable future unlock date (6 Months, 1 Year, 3 Years, or Custom).
- **Status Gating:** Content remains sealed with countdown graphics until wall-clock time exceeds unlock timestamp.

### Feature 15: Printable Emergency & Asset Summary Sheet
- **Confidential Document Architecture:**
  - Displays emergency contacts, medical details (blood group, primary hospital), bank accounts, and insurance policies.
  - Automatic masking of account numbers (`•••• •••• 9214`) with temporary unmask toggles.
  - Physical locker and safe key instructions.
- **Print Layout:** Dedicated `@media print` CSS rules hiding navigation, dark theme backgrounds, and action buttons to produce clean, ink-friendly printed physical sheets.
